# AI Community Crawler

커뮤니티 동향 모니터링 과정에서 반복적으로 발생하는 데이터 수집 업무를 개선하기 위해 제작한 자동화 도구입니다.

단순 게시글 수집 기능에서 시작해 실제 사용 과정에서 발견한 문제를 바탕으로 기능을 단계적으로 개선했습니다.

## Project Overview

기존에는 커뮤니티 게시글을 직접 확인하거나 개발사에서 별도로 전달받은 크롤링 데이터를 활용해 동향을 취합했습니다.

특히 게시글의 제목과 본문을 하나씩 확인하고 필요한 데이터를 정리하는 과정에서 반복 작업이 많이 발생했습니다.

이를 개선하기 위해 GPT를 활용하여 요구사항 정의, 구현, 테스트, 오류 수정 과정을 반복하며 커뮤니티 데이터 수집 자동화 도구를 제작했습니다.

## Development Process

### 1. 게시글 자동 수집
- 게시글 제목 및 본문 자동 수집
- 작성일시, 작성자, 글번호, 링크 등 관련 데이터 수집

### 2. 중복 데이터 제거
- 기존 수집 데이터와 글번호 비교
- 이미 수집한 게시글을 제외하고 신규 게시글만 수집

### 3. Excel 파일 관리 개선
- 기존 결과 파일을 덮어쓰지 않도록 개선
- 실행할 때마다 새로운 번호가 부여된 Excel 파일 생성

### 4. 주요 게시글 강조
- 추천 수 또는 댓글 수가 일정 기준 이상인 게시글 자동 강조
- 확인 우선순위가 높은 게시글을 빠르게 식별할 수 있도록 개선

### 5. 실행 및 배포 환경 개선
- Python 개발환경이 없는 PC에서도 사용할 수 있도록 실행 파일 형태로 배포
- 사용자가 수집할 페이지 범위를 직접 지정할 수 있도록 구성

### 6. 예외 상황 대응
- 커뮤니티 접근 제한 감지 기능 적용
- 접근 제한 발생 시 추가 요청을 중단하고 수집된 데이터 저장

## AI Utilization

GPT를 개발 과정의 협업 도구로 활용했습니다.

업무에서 필요한 기능을 직접 정의하고, 기능 단위로 요구사항을 전달하여 코드를 구현했습니다. 이후 실제 실행 과정에서 발생한 오류와 개선점을 다시 분석하고 프롬프트와 코드를 수정하는 과정을 반복했습니다.

이를 통해 프로그래밍 자체보다 업무상의 문제를 정의하고 AI를 활용해 실제 사용 가능한 자동화 도구로 구현하는 경험을 쌓았습니다.

## Tech Stack

- Python
- GPT
- Requests
- BeautifulSoup
- Pandas
- OpenPyXL

## Result

반복적으로 게시글을 열어 데이터를 수집하던 과정을 자동화하고, 수집 결과를 Excel 형태로 정리하여 이후 동향 분석 및 취합 업무에 활용할 수 있도록 개선했습니다.
